# 🌐 Frontend

Clone repository frontend

```bash
git clone https://github.com/HUU7911/web-app.git
```

Change directory folder:

```bash
cd web-app
```

Install dependencies:

```bash
npm install
```

Chạy development server:

```bash
npm run dev
```

Frontend sẽ kết nối tới API Gateway.
